# Fereastra Germană Iași

Site demonstrativ multipagină pentru o firmă locală de ferestre și uși.

## Pagini

- Acasă
- Ferestre
- Uși
- Servicii
- Proiecte
- Contact cu mesaj pregătit pentru WhatsApp

## Rulare locală

Site-ul este static. Poate fi deschis direct sau servit cu orice server HTTP local.

## Publicare

Proiectul include `vercel.json` și poate fi importat direct în Vercel.

Imaginile sunt generate pentru această machetă și trebuie înlocuite cu fotografiile reale ale firmei în versiunea finală.
